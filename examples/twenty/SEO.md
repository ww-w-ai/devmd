# Twenty CRM — SEO Strategy

## Architecture: Split Approach

Twenty uses a split architecture for SEO. The CRM application (React SPA) is behind authentication and must not be indexed. All SEO efforts focus on the marketing site and documentation.

```
twenty.com (Next.js — SSR, indexable)
  ├── Landing page
  ├── Pricing
  ├── Blog
  ├── Changelog
  └── About

docs.twenty.com (Documentation — indexable)
  ├── Getting Started
  ├── API Reference
  ├── SDK Guides
  └── Self-Hosting

app.twenty.com (React SPA — NOT indexable)
  ├── /auth/login
  ├── /objects/*
  ├── /settings/*
  └── All routes: noindex, nofollow
```

## Marketing Site SEO (twenty-website-new)

### Server-Side Rendering

Next.js provides SSR for all marketing pages. Every page renders complete HTML on the server for search engine crawling.

### Meta Tags

```html
<!-- Example: Landing page -->
<title>Twenty — Open Source CRM</title>
<meta name="description" content="The open source CRM alternative to Salesforce. Self-host or use Twenty Cloud. Custom objects, GraphQL API, AI agents." />
<meta property="og:title" content="Twenty — Open Source CRM" />
<meta property="og:description" content="Build the CRM you actually want to use." />
<meta property="og:image" content="https://twenty.com/og/home.png" />
<meta property="og:type" content="website" />
<meta name="twitter:card" content="summary_large_image" />
<link rel="canonical" href="https://twenty.com/" />
```

### Structured Data

```json
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "Twenty",
  "description": "Open source CRM — alternative to Salesforce",
  "applicationCategory": "BusinessApplication",
  "operatingSystem": "Web",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "USD"
  },
  "author": {
    "@type": "Organization",
    "name": "Twenty",

```

### Blog SEO

- Each blog post gets unique meta title, description, OG image
- Structured data: `BlogPosting` with author, datePublished, dateModified
- Internal linking between related posts
- RSS feed at `/blog/rss.xml`

## CRM App — SEO Blockers

The SPA application intentionally blocks all indexing:

```html
<!-- In index.html -->
<meta name="robots" content="noindex, nofollow" />
```

```
# robots.txt for app.twenty.com
User-agent: *
Disallow: /
```

No SSR needed for the CRM app — all content is behind authentication and contains private workspace data.

## AI Crawler Policy

For the marketing site:
- **Search indexing**: Allowed (standard crawlers)
- **AI training**: Blocked (`ai-train: no`)
- **AI search/input**: Allowed (`ai-input: yes` — answers can cite Twenty docs)

## Documentation Site

The docs site at `docs.twenty.com` is fully indexable with:
- SSR or static generation
- TechArticle structured data per page
- Internal search (optional Algolia integration)
- Version-specific documentation URLs
- Canonical URLs to prevent duplicate content
